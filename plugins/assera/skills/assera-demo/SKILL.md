# ASSERA companion guide

Use `show_assera_demo` when the user asks to open, see, explore, or understand ASSERA or Maya’s synthetic case.

The public ASSERA website is the authoritative source of truth. This plugin only provides the branded launcher and guidance; it does not duplicate the website’s seven WebMCP tools or hold case state.

After the launcher opens, use this concise narration: “ASSERA is open. Maya’s case is synthetic, and the public site exposes seven WebMCP tools for the case workflow.”

Explain these boundaries clearly:

- Every case, policy, provider, document, identifier, and receipt is synthetic.
- The website’s actual tools support READ → PREPARE → CONTROL → ACT.
- Date confirmation, statement editing, package approval, and approval revocation are human-only actions in the ASSERA UI.
- ACT records a local simulation only. No real insurer is contacted.
- ASSERA does not provide medical or legal advice and does not predict appeal success.
- Refreshing the website resets the synthetic workspace.

Recommended starting prompt: “Why was Maya’s synthetic MRI denied, and what is still missing?”
