# Video shot list

## Pre-recording

- Use a clean WebMCP-eligible browser profile and a fresh case refresh.
- Confirm public/judge access or use an owner-authenticated capture only for a
  draft that will be replaced before submission.
- Silence notifications; close personal tabs; hide bookmarks/account details.
- Check microphone, narration levels, cursor visibility, and 1080p+ capture.
- Verify exactly seven tools and the final public URL/commit.
- Rehearse to 2:35; keep the final export under three minutes.

## Reset and fallback

Refresh the case route before every take. If an agent selects a different valid
READ order, keep the take if all required state is read and no PREPARE/ACT occurs.
If a tool snapshot is stale, refresh and restart the take; do not splice a
misleading state. If ACT arguments are wrong, stop and restart after fixing the
agent prompt/metadata—not the package guards.

Before upload, add accurate captions/subtitles, verify clear audio, confirm no
copyrighted music, set YouTube visibility to Public, and test the link signed out.
